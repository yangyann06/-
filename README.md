# 淘寶商品採集 → Yahoo 購物中心批量上架工作台（MVP v0.1）

## 目前可用功能
- 批量貼上淘寶／天貓商品網址，檢查網址格式和重複項目
- 匯入 CSV、下載 CSV 範本
- 手動編輯標題、分類、價格、SKU、庫存、圖片網址
- 商品資料使用權確認欄位
- 狀態管理：待整理、待審核、已審核、已上架（手動記錄）
- 匯出全部或已審核商品 CSV
- 瀏覽器 localStorage 本機保存

## 重要限制
- 貼上網址不會自動抓取淘寶商品資訊；請使用獲授權 API 或供應商提供且允許使用的匯出檔。
- 未連接 Yahoo WebService API，CSV 不是保證可直接匯入 Yahoo 的正式格式；必須按你的商店後台模板/API schema 對應欄位。
- 「已上架」是手動狀態，不代表真的已發布。
- 本機保存只存在目前瀏覽器/裝置，不適合多人協作；清除瀏覽器資料可能遺失，請定期匯出 CSV。
- 不要把 API Key、Shared Secret 或 access token 放在前端 HTML/JavaScript。正式版應使用伺服器端 API 路由與密鑰管理。
- 使用前確認商品圖片、標題、描述與品牌素材的使用權。

## 部署到 Vercel（靜態網站）
1. 將 `index.html` 放在一個 GitHub 儲存庫根目錄。
2. 在 Vercel 選擇 Add New Project，匯入該儲存庫。
3. Framework Preset 可選 Other；Build Command 留空；Output Directory 使用 `.`（或依 Vercel UI 指引）。
4. 部署後用 HTTPS 網址開啟即可。
5. 此版本沒有伺服器、資料庫或 API 密鑰設定，不會向淘寶或 Yahoo 發送刊登請求。

## 正式版 API 對接前檢查
### 淘寶
- 確認開放平台應用類型、獲批 API、授權帳號、商品資料可取得範圍與資料使用條款。
- 使用官方授權流程取得 token；在伺服器端呼叫 API，記錄錯誤碼及授權到期時間。
### Yahoo 購物中心
- 以商店提供的官方文件確認認證流程、商品新增/更新端點、必填欄位、分類屬性、圖片規則、SKU/規格模型、速率限制。
- API Key / Shared Secret 僅存伺服器端環境變數或密鑰管理服務。
- 先測試一件商品；確認回應成功後再擴到每批最多 50 件。
- 加入重複刊登防護、重試策略、逐筆結果、人工確認與操作日誌。

## 建議的正式版架構
- 前端：Next.js 管理台
- 後端：Next.js Route Handlers 或獨立 Node.js API
- DB：PostgreSQL
- 圖片：具有使用權的圖片檔存放在物件儲存
- 背景工作：批次任務佇列；每件商品記錄採集、審核、提交與回應狀態
- 認證：管理員登入、權限控制、操作審計
